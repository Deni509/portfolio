# Visual system

Mode: Experience. Personal portfolio for freelance proposals, Spanish and English.
Direction: sculptural digital atelier. A living copper mathematical knot establishes the connection between creative interfaces and engineering. Quiet warm charcoal surfaces frame the work; project presentations use distinct materials, generous typography and editorial rhythm.

Tokens: background #131311, paper #eeece5, secondary #b4b3aa, copper #e1a87e, divider #3c3b35. Space Grotesk display; Manrope body. Display maximum 96px, tracking minimum -0.04em. Outer gutter 5.5%, mobile breakpoint 760px. No gated loading animation. Canvas pauses offscreen, on explicit pause and when reduced motion is requested. Content and navigation remain native HTML.

Facts: no invented metrics, client testimonials or production readiness claims. AJAX links to an existing case study. ANACAPTEC is a summary with conceptual graphic artwork. HTML5 ads remain labeled demonstrations.
